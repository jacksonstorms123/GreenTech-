# GreenTech-
An environmental monitoring and autonomous plant-care project.

Project Overview

A 24-week project focused on building an intelligent environmental monitoring and automated watering system.

The system will eventually monitor:

Temperature

Humidity

Soil moisture

It will use sensors, a microcontroller, Python, and automated watering to help manage plant-growing conditions.

Project Goals

Learn Python programming.

Learn basic electronics and robotics.

Build an environmental monitoring system.

Implement automated watering.

Collect and visualize environmental data.

Compare automated watering with manual watering.

Current Progress

Week 1: Python Greenhouse Simulator

Created a basic greenhouse simulator using Python.

Practiced variables and user input.

Added environmental condition checks.

Created warnings for unfavorable conditions.

Upcoming Work

Week 2: Python data collection and visualization.

Week 3: Microcontroller setup.

Future weeks: Sensor integration and automated watering.
